# AI Model Gateway Docs

Start here if you are evaluating, installing, operating, or promoting AI Model Gateway.

AI Model Gateway is a self-hosted LLM operations gateway for teams that want local control over provider routing, config publishing, telemetry, benchmarks, diagnostics, updates, and rollback.

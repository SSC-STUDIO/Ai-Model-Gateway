## 最严重发现快速索引

1. **SEC-001 (Critical)** — 上游转发路径未启用 `NewSafeTransport`，存在 DNS rebinding TOCTOU 漏洞。`ValidateURL` 在 `forward.go:28` 解析一次 DNS，但 `sharedHTTPClient` 在 `handler.go:27` 未使用 `pinnedIPDialer`，导致 TLS 握手前可能重新解析到内网 IP。
2. **SEC-002 (Critical)** — `ReplayHandler.Replay` (`replay.go:199`) 把数据库里存的 `req.Path` 与 `gatewayURL` 直接字符串拼接，且 replay HTTP client 无鉴权。路径来源是 request_facts 表，若攻击者此前能成功让路径登记为 `//evil.com/x` 或含 `..`，重放会向自己/外部端点发起未鉴权请求。
3. **SEC-004 (High)** — `fetchPricingPage` (`pricing_catalog.go:142`) 抓取 admin 可配置的 pricing URL 时未走 SSRF 安全传输，可被用来探测内网。
4. **CONC-001 (High)** — `queue.schedule` (`queue.go:232`) 的 `go func(r PendingRequest)` 未设 `defer recover`。请求 panic 会让 scheduler goroutine 崩溃，同时不归还 semaphore slot 导致死锁放大。
5. **ERR-001 (High)** — `Store.persistBatch` (`store.go:1010, 1023`) 默默吞掉 `tx.Begin()` / `tx.Rollback()` 错误，不记日志、不发指标，batch 数据永久丢失且无告警。
6. **FE-001 (High)** — 5 种 locale (ja/ko/es/fr/de) 各缺 205 个翻译 key，用户会看到 i18n key 原文（如 `"config.intercept.rules"`）。CI 未检查 locale 一致性。

## 误报剔除概览

6 条候选最终判定为误报或非问题：

1. `streaming.go:43` 每行 `flusher.Flush()` — 看似 per-line flush 性能问题，但 SSE 实时输出必要，非 bug。
2. `auth/cookie.go:197` 兼容 legacy `timestamp` payload — 看似逻辑错误，实为旧 cookie 兼容设计。
3. `os.Exit` 出现在 `cmd/*/main.go` — 属 main 程序合规用法，非 library 代码。
4. TypeScript `Charts.tsx` 导入 `memo` 但不使用 — 已在本次会话前半段重构为 barrel export，导入被新文件继承，非问题。
5. `store.go:1018–1019` `_ = requestStmt.Close()` — prepared-statement close 在 defer 链中忽略错误是 Go 习惯用法，rows 已全部处理完毕，非 bug。
6. `pathsecurity.SanitizePath` 返回空串表示失败 — 看似不一致 API，但函数注释和调用点均已对空值做 guard，非 bug。

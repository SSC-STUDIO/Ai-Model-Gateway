# Code of Conduct

AI Model Gateway is an open source project for people building and operating LLM infrastructure. The project welcomes practical, technical participation from users, maintainers, and contributors.

## Expected Behavior

- Be respectful and direct when discussing code, design, operations, and project direction.
- Keep feedback specific, actionable, and grounded in observable behavior.
- Assume shared intent to improve reliability, security, compatibility, and maintainability.
- Respect different experience levels, deployment environments, and operational constraints.
- Redact secrets, tokens, customer data, internal endpoints, and private logs before posting.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Discriminatory language or exclusionary behavior.
- Publishing private information without explicit permission.
- Posting real API keys, credentials, tokens, or sensitive operational data.
- Spam, repeated low-effort promotion, fake engagement, or requests for artificial stars.

## Reporting Problems

For public project conduct problems, open a GitHub issue only if the report can be made without exposing private information.

For sensitive reports, contact the maintainer privately through a channel available to the maintainer account. Security-sensitive vulnerabilities should follow the [Security Policy](SECURITY.md).

Reports should include:

- A short description of what happened
- Links, screenshots, or message references when safe to share
- Any immediate moderation or project action requested

Maintainers may remove comments, close threads, block participants, or take other reasonable action when behavior harms the project or its contributors.

## Scope

This code of conduct applies to project spaces including GitHub issues, pull requests, discussions, release comments, and project-related community conversations where maintainers are representing AI Model Gateway.
